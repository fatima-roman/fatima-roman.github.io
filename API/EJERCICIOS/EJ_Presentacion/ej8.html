📋 Códigos de Estado HTTP (Presentación)

CódigoNombreSignificado
200OK✅ Petición exitosa. GET recibido y procesado.
201Created✅ POST ejecutado: se creó un nuevo recurso.
304Not Modified↪️ El recurso no cambió; el navegador usa caché.
400Bad Request⚠️ El servidor no entiende la petición (JSON mal formado).
401Unauthorized⚠️ Necesitas autenticarte primero.
403Forbidden⚠️ Sin permisos (ej: el error de Git de antes).
404Not Found⚠️ Recurso no encontrado.
405Method Not Allowed⚠️ Método HTTP no permitido en esa URL.
500Internal Server Error❌ Error interno del servidor.
503Service Unavailable❌ Servidor caído o en mantenimiento.
